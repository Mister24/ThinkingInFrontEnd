# ThinkingInFrontEnd

![HTML](https://img.shields.io/badge/HTML-静态-blue.svg)

> 前端（HTML）基础学习笔记，按章节组织的可运行示例。

## 项目简介
以「一章一个目录、一节一个 HTML 文件」的方式记录 HTML 基础，边看标签语义边写示例，适合零基础入门对照学习。

## 环境要求
- 任意现代浏览器（双击 `.html` 即可打开）
- 无需构建工具、无需依赖

## 目录结构（按章节）
```
├── chapter03_基本标签/    # body、基本文档结构
├── chapter04_文本标签/    # 标题、段落、div、块 / 行内元素、特殊符号
├── chapter05_列表/        # 有序 / 无序 / 定义列表
├── chapter06_表格/        # 表格与合并单元格
├── chapter07_图片/        # 图片标签
├── chapter08_超链接/      # 普通 / 内部 / 锚点链接
├── chapter09_表单/        # 表单元素
└── images/                # 示例图片资源
```

## 使用方式
直接用浏览器打开对应章节下的 `.html` 文件即可查看渲染效果。
